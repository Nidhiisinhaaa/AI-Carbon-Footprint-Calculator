# 🌍 CarbonIQ

An AI-powered web app that estimates an individual's yearly carbon footprint (kg CO2/year) from everyday lifestyle habits — diet, transport, home energy, digital usage, and waste — and provides personalized, actionable recommendations to reduce it.

## Features

- **Hero landing + navigation** — a gradient hero banner with **Home / About / Contact** pages.
- **ML-powered prediction** — estimates yearly CO2 emissions from 30+ lifestyle features using a trained regression model.
- **Grading system** — A–F letter grade based on your predicted footprint, with color-coded feedback.
- **User segmentation** — KMeans clustering places you into one of four segments: Eco Warrior, Green Beginner, Average Consumer, or High Emitter.
- **Interactive dashboard** — four tabs:
  - *Your Breakdown* — donut + bar charts of your CO2 by category vs. the dataset average.
  - *Global Comparison* — how you compare to country-level averages (India, USA, UK, China, Germany, Brazil, Japan, world average).
  - *What-If Simulator* — toggle lifestyle changes (vegan diet, public transport, less shopping, less screen time, full recycling) and see projected savings instantly.
  - *Carbon Gauge* — a gauge visualization of your footprint against 0–20,000 kg CO2/year zones.
- **Personalized recommendations** — a rules-based engine surfaces the highest-impact changes you can make, ranked by potential savings.
- **Carbon offset calculator** — translates your footprint into trees, solar panels, and car-free days needed to offset it.
- **PDF report export** — download a 5-page report summarizing your inputs, breakdown, recommendations, and offsets.
- **Light theme UI** — clean white background with a red/pink/peach accent palette (`#F43F5E` / `#EC4899` / `#FFB4A2`), configured via `.streamlit/config.toml`.

## Tech Stack

- **Modeling**: scikit-learn (Random Forest, Linear Regression, KMeans), XGBoost
- **Data**: pandas, numpy
- **App**: Streamlit
- **Visualization**: Plotly (interactive dashboard), Matplotlib/Seaborn (notebook EDA)
- **PDF Reports**: fpdf2
- **Persistence**: joblib

## Installation

1. **Clone the repository**
   ```bash
   git clone <repo-url>
   cd carbon-footprint-calculator
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Download the dataset**
   Get the "Carbon Emission" dataset from Kaggle (see attribution below) and place it at:
   ```
   data/carbon_emission.csv
   ```

4. **Run the training notebook** (generates the cleaned dataset + all model artifacts in `models/`)
   ```bash
   jupyter notebook notebooks/model_training.ipynb
   ```
   Run all cells top to bottom.

5. **Launch the app**
   ```bash
   streamlit run app/app.py
   ```
